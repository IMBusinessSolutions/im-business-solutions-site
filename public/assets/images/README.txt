IMAGE DE FOND DU HERO
=====================

Déposez ici la photo d'architecture utilisée en arrière-plan du hero,
nommée exactement :

    hero-bg.jpg

Recommandations :
- Format : JPG (ou WebP -> adapter l'URL dans css/style.css)
- Dimensions : ~2400 x 1400 px, cadrage exploitable à droite de l'image
- Poids : < 350 Ko (compresser via squoosh.app ou tinyjpg.com)

Tant que le fichier est absent, un dégradé bleu nuit + texture dorée
s'affiche automatiquement à la place (voir .hero__bg dans style.css).
